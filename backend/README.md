# EzWash Backend

The EzWash backend is an Elysia service supporting the car wash web application.

## Prerequisites

- Bun 1.0+ installed
- Node.js 20+ available if using npm from the repository root
- Git for repository management

## Setup

From the repository root:

```bash
npm install
```

From the `backend/` directory:

```bash
npm install
```

## Run

From `backend/`:

```bash
npm run dev
```

This starts the backend service in watch mode.

## Notes

- The backend is built with Elysia and intended to serve the EzWash API.
- Keep backend dependencies minimal and consistent with the workspace.
- Use the root workspace scripts for shared development commands when needed.
