# EzWash Frontend

The EzWash frontend is a React + TypeScript app powered by Vite.

## Prerequisites

- Node.js 20+ installed
- npm or Bun available on the command line
- Git for repository checkout

## Setup

From the repository root:

```bash
npm install
```

From the `frontend/` directory:

```bash
npm install
```

## Run locally

From `frontend/`:

```bash
npm run dev
```

Open the URL shown by Vite in your browser to view the app.

## Build

From `frontend/`:

```bash
npm run build
```

## Lint

From `frontend/`:

```bash
npm run lint
```

## Preview

After building, preview the production build:

```bash
npm run preview
```

## Notes

- The frontend uses Vite for rapid development and production builds.
- Maintain dependency alignment with the monorepo.
- Use root workspace scripts for cross-cutting tasks when working with both frontend and backend.
